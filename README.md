# MochiLog Web

**MochiLogの機能と使い方を紹介する公式サイトです。**

iPhone・iPadのバッテリー記録を始めたい方へ、解析ログの取り込み方、容量や充放電回数の見方、便利な連携機能を案内しています。

[公式サイト](https://mochilog.ryuya-dev.net/) · [使い方](https://mochilog.ryuya-dev.net/guide?lang=ja) · [App Store](https://apps.apple.com/app/mochilog/id6756904240) · [TestFlightベータ](https://testflight.apple.com/join/vnHYsRgN)

履歴プレビューは説明用のサンプルです。実際の解析ログの取り込みや記録はMochiLogアプリで行います。

## アプリとPC版

- [MochiLog](https://github.com/MochiLog/MochiLog)：iPhone・iPadの記録・分析アプリ
- [MochiLog Mac](https://github.com/MochiLog/MochiLog-Mac)：Macからログの収集・転送を行うコンパニオン
- [MochiLog Windows](https://github.com/MochiLog/MochiLog-Windows)：Windowsからログの収集・転送を行うコンパニオン

開発中の機能やベータ版は、公開版と利用できる内容が異なる場合があります。対応環境と条件は各ガイドをご確認ください。

## English

The official MochiLog website introduces the app and explains how to import Apple analytics files, read battery capacity and cycle counts, and set up optional companion features.

Visit the [website](https://mochilog.ryuya-dev.net/?lang=en), [user guide](https://mochilog.ryuya-dev.net/guide?lang=en), or [support page](https://mochilog.ryuya-dev.net/support?lang=en). The site supports Japanese and English on phones, tablets and computers. Its battery-history preview uses sample data; import your own analytics files in the MochiLog app. Beta features may differ from the App Store version.
